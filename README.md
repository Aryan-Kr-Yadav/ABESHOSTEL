# 🏠 ABES Hostel Portal

A modern and responsive **Hostel Management Website** built using **HTML, CSS, and JavaScript**.  
This project provides an interactive platform for students to explore hostel facilities, check amenities, and manage hostel-related activities.

---

## 🚀 Features

- 🌐 Responsive and clean UI design  
- 🏠 Home page with attractive hero section  
- ℹ️ About section with hostel details  
- 🛏️ Hostel listing and information  
- 🛠️ Amenities overview  
- 💰 Fees structure display  
- 🖼️ Gallery section  
- 📞 Contact section  
- 🔐 Student Login & Account Activation UI  
- 🌙 Dark mode toggle  

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & layout  
-  **JavaScript (Vanilla JS)** – Interactivity
